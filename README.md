# 🛍️ ColorPop – Colorful E-commerce Website

## 📌 About the Project

ColorPop is a modern, colorful, and responsive e-commerce website developed as a college project using HTML5, CSS3, and vanilla JavaScript. It provides an interactive online shopping experience with vibrant UI elements, smooth animations, and user-friendly navigation.

## ✨ Features

- 🎨 Colorful design with smooth animations and hover effects
- 🛒 Product catalogue with product details
- 🔍 Product search and category filtering
- ↕️ Product sorting and price filtering
- ❤️ Wishlist functionality
- 🛍️ Shopping cart with quantity controls
- 🎟️ Coupon and discount calculations
- 📝 Checkout form with input validation
- ✅ Simulated order confirmation
- 📦 Order history
- 💾 Local storage for saving cart and wishlist data
- 📱 Responsive layout for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, responsive design, and animations
- JavaScript – Interactive functionality and shopping logic
- Browser Local Storage – Client-side data persistence

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the products and test the shopping features.

## ⚠️ Limitations

This is a frontend-only demonstration project. It does not include a backend server, a real database, user authentication, or actual payment processing. Shopping cart, wishlist, and sample order data are stored locally in the browser.

## 🎯 Project Objective

The objective of ColorPop is to demonstrate frontend web development skills by creating an attractive, interactive shopping interface using HTML, CSS, and JavaScript.
