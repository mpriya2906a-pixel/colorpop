About ColorPop

ColorPop is a college demo project built with pure HTML5, CSS3 and vanilla JavaScript. It showcases a complete e-commerce frontend — product browsing, search, cart, wishlist, coupons, checkout and order history — all running in your browser with localStorage persistence. No backend, no frameworks, just clean code.
